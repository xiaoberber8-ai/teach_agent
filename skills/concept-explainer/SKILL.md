# 概念讲解技能（concept-explainer）

适用触发词：是什么、怎么理解、什么叫、区别、联系、为什么需要、直观上、含义。

## 执行流程（按序）

1. **先取证再开口**：用 `search_book` 检索概念名 + 英文原名 + 常见同义说法
   （如"过拟合 / overfitting / 过学习"），至少命中 1 个片段再讲；
   定义类问题追加 `read_chunk(include_adjacent=true)` 读完整小节开头。
2. **一句话直给**：开篇第一句必须是"X 是……"的陈述句，禁止用"这是一个很重要的概念"开场。
3. **生活类比（30 秒可懂）**：选一个与检索到的定义结构同构的日常类比，
   并明确指出类比在哪里会失效（"但类比到这里就不成立了……"）。
4. **教材定义还原**：用教材自己的表述给出严谨定义，首次出现的符号逐个解释，
   标注（《书名》 第x页 · 章节）。教材说法与你的直觉表述不同时以教材为准。
5. **正例 + 反例各一个**：优先用书里的例子（如西瓜书就用"好瓜"数据集）；
   反例要具体到"满足 A、B 但不满足 C，所以不是 X"。
6. **易混辨析（如检索到相邻概念）**：用三行表格对比——
   | 维度 | X | 易混概念 Y |，维度从教材原文提炼，不要凭空造。
7. **一句话自测（强制）**：结尾给一道判断/选择式小题（答案当场不下发），
   学生作答后**立即**只回应"对/不对 + 一句理由"，不追加新内容。
   选择题各选项字数/词数尽量相同，正确项不得明显更长更短。
   注意"看懂了"只是流畅度错觉：他答对后可再追问一个没见过的小变式
   验证存储强度，而不是重复讲解。

## 输出模板

```
**一句话**：X 是……。

**直觉类比**：……（类比失效点：……）

**教材定义**：……（《书》 第x页 · x.x 节名）
- 符号：… 表示……；… 表示……

**正例**：……
**反例**：……满足……但不满足……，所以不是 X。

**和 Y 的区别**：
| 维度 | X | Y |
|---|---|---|
| … | … | … |

**自测（先别看答案）**：判断下面说法对不对：……
```

## 硬性约束

- **一次只给一个可达成的小赢**：概念复杂时（如"贝叶斯判定准则"牵扯
  风险、损失、后验），本次只讲一个核心点，明确告诉学生其余部分下次再讲。
- **按水平伸缩**：初学者的正例反例用书里例子即可；进阶学生跳过类比，
  直接给定义 + 易混辨析 + 变式。判断不准时先用一个二选一小问题探底。
- 类比、正例、反例中若出现事实性断言，必须能在检索片段中找到依据；
  找不到依据的例子只能标注"这是我编的辅助例子，书里没有"。
- 学生只问一句话定义时，只输出第 2、4 步，不强行展开全部七步。
- 检索 2-3 个说法仍无结果 → 进入拒答，不允许用参数记忆补定义。
