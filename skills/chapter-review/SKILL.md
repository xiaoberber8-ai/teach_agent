# 章节复习与自测技能（chapter-review）

适用触发词：复习、串讲、总结、考点、提纲、考前、知识框架、自测、这一章。

## 执行流程（按序）

1. **定位章节真实边界**：
   - 学生给了章号就 `search_book(query=章名/主题, book_id=...)` 多点检索
     （至少 3 组不同关键词），再用 `read_chunk` 抽查章首与各小节；
   - 依据命中片段里出现的小节标题（如 4.1/4.2/4.3）列目录，
     **不允许凭模型记忆补出这一章"应该有"但检索不到的小节**；
   - 无法确认某小节是否属于该章时，在提纲中标注"（未在书中检索到，请核对目录）"。
2. **画一页知识地图**：用缩进列表表达"章 → 小节 → 核心概念/方法"，
   每条后面标页码；同一方法若在不同小节演进（如 ID3→C4.5），
   用箭头串起来并各标页码。
3. **核心结论卡（每小节 1-3 条）**：每条格式
   `【结论】…【条件/前提】…【页码】…`，结论必须是检索原文支持的命题，
   不得是你的二次发挥。
4. **高频考点与题型归纳**：只从书里的例题、公式、明确强调的注意事项归纳，
   分成"会算的题（给公式与页码）/ 会辨析的概念（给对比双方与页码）/
   会推导的证明（给起点假设与页码）"三类。
5. **盲测题单（主动回忆 + 交错）**：每个小节出 1 道题，总量控制在 5-9 道：
   - 60% 闭卷问答/口算（答案能在 1-2 页教材内定位）；
   - 30% 概念辨析（要求学生说出区别并举自己的例子）；
   - 10% 开放串联（"用本章方法解释……"）。
   - **交错排题**：相邻两题不得出自同一小节（复习阶段混题型才能训练
     "识别该用哪个知识"）；但初学阶段的随堂练习不交错。
   - 选择题各选项等长，正确项无格式规律。
   出题时只给题干；学生回复后**逐题即时批改**，批改前重新 `search_book`
   核对答案依据，禁止凭记忆判卷。全对的题在后续复习中降频，做错的题
   进入下一轮重点。
6. **安排间隔自测**：结尾给三个检查点——今天结束前 / 明天 / 三天后
   各盲测同一题单一次；只提醒节奏，不替学生排满日程。

## 输出模板

```
# 第 X 章《章名》复习（共检索到 n 个小节）

## 知识地图
- X.1 …（第a页）
  - 概念：… / 方法：…
- X.2 …（第b页）
  - … → …（第b→c页）

## 核心结论卡
- 【结论】…【前提】…【页码】第x页

## 考点分类
- 会算：…（式 x.y，第x页）
- 会辨析：… vs …（第x-y页）
- 会推导：…（起点假设见第x页）

## 盲测题单（先闭卷做，做完我再逐题批）
1. …
2. …
```

## 硬性约束

- 复习材料的信息密度优先于完整性：检索证据不足的小节宁缺毋滥。
- 不得出现"本章还介绍了……"这类无法在原文定位的句子。
- 一次复习只处理学生指定的章；跨章关系只在检索片段明确提及时才画连线。
